# Road_Accidents_EDA_Python
Exploratory Data Analysis (EDA) of road accident data using Python, Pandas, NumPy, Matplotlib, and Seaborn. Includes data cleaning, outlier analysis, and 50 different data visualizations to explore accident patterns and relationships.
# 🚦 Road Accident Data Analysis using Python

## 📌 Project Overview
This project focuses on Exploratory Data Analysis (EDA) of road accident data using Python. The goal is to explore accident-related patterns, understand the factors associated with road accidents, and identify useful insights through data analysis and visualization.

## 🎯 Objectives
- Explore road accident data and understand its structure.
- Identify and handle missing values and duplicate records.
- Analyze numerical and categorical variables.
- Explore outliers in the dataset.
- Create visualizations to identify patterns and relationships.
- Practice different chart types to improve data visualization skills.

## 📊 Dataset Description
The dataset contains road accident information, including:

- Accident date and city
- Road type and weather conditions
- Vehicle type and speed limits
- Number of vehicles involved
- Casualties and fatalities
- Emergency response time
- Traffic volume
- Estimated property damage

*Note: The dataset is used for learning and analysis purposes.*

## 🛠️ Tools & Libraries
- **Python** – Programming language
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualizations
- **Squarify** – Treemap visualization

## 🔍 Analysis Performed
- Data inspection and exploration
- Missing-value and duplicate-value analysis
- Outlier exploration
- Analysis of numerical and categorical variables
- Visualization of accident-related patterns
- Creation of multiple chart types, including distribution plots, relationship plots, categorical plots, and other advanced visualizations

## 📈 Key Learning Outcomes
- Improved understanding of the EDA workflow.
- Practiced data cleaning and preprocessing techniques.
- Learned to select suitable visualizations for different types of data.
- Developed skills in interpreting patterns and relationships in a dataset.

## ▶️ How to Run
1. Download or clone this repository.
2. Open `Road_Accidents.ipynb` in Jupyter Notebook or Visual Studio Code.
3. Install the required libraries if they are not already installed.
4. Run the notebook cells in order.
